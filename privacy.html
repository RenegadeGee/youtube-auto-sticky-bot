YouTube Auto Sticky Bot — Privacy Policy

Effective date: September 5, 2026

This Privacy Policy explains what information YouTube Auto Sticky Bot (“the Bot”) processes, why it is used, and the choices available to Discord server administrators.

1. Information the Bot processes

Server configuration data

The Bot may store limited configuration information needed to operate:

  • Discord server (guild) ID;
  • configured Discord channel ID;
  • the Bot’s current sticky message ID;
  • selected YouTube channel handle, URL, or channel ID;
  • the most recently detected YouTube video ID or URL;
  • server-specific sticky header text;
  • server-specific sticky delay settings.

Temporary command and runtime data

The Bot may temporarily process the Discord user ID and server ID of someone using certain administrative commands for permission checks and cooldowns. It also receives message events in the configured channel so it knows when to move the sticky back to the bottom.

The Bot is not designed to store the content of ordinary Discord messages.

YouTube lookup cache

To reduce YouTube Data API usage, the Bot may cache mappings between a YouTube handle, URL, or video and the corresponding YouTube channel ID.

2. How information is used

  • Remember which Discord channel should contain the sticky.
  • Remember which YouTube channel a server follows.
  • Detect and display the newest YouTube upload, Short, or livestream.
  • Move the sticky after new Discord activity.
  • Provide server-specific configuration and slash commands.
  • Prevent command spam and reduce unnecessary YouTube API requests.
  • Troubleshoot errors and maintain the service.

3. Information the Bot does not intentionally collect

The Bot is not designed to collect or store Discord passwords, ordinary message contents, payment information, precise location information, or sensitive personal information.

The Bot’s Discord token and YouTube API key are private service credentials controlled by the Bot operator and are not collected from users.

4. Third-party services

The Bot depends on third-party services that may process information under their own privacy policies, including Discord, YouTube / Google, and the Bot’s hosting provider. The Bot operator does not control those third parties’ privacy practices.

5. Data retention

Server configuration is retained while the Bot remains configured for that server.

Running /sticky stop removes that server’s active configuration from the Bot’s configuration store. Temporary cooldown information is held only in memory and is lost when the Bot restarts.

Operational logs, hosting backups, or cached technical data may remain for a limited period as part of normal service operation.

6. Data sharing

The Bot operator does not sell user data. Information may be shared only when necessary to operate the Bot through the third-party services described above, to comply with legal obligations, or to protect the security and integrity of the Bot and its users.

7. Server administrator choices

  • View the current configuration with /sticky status.
  • Change the YouTube or Discord channel with /sticky setup.
  • Change server-specific header or delay settings.
  • Remove the active configuration with /sticky stop.
  • Remove the Bot from the Discord server.

8. Security

Reasonable measures are used to protect the Bot’s credentials and configuration data. However, no online service can guarantee absolute security.

9. Children’s privacy

The Bot is intended for use in accordance with Discord’s age requirements and policies. The Bot is not designed to knowingly collect personal information from children.

10. Changes to this Privacy Policy

This Privacy Policy may be updated from time to time to reflect changes to the Bot, its hosting, its features, or applicable requirements.

11. Contact

For privacy questions, deletion requests, or other concerns relating to the Bot, contact the Bot operator through the Discord account or support method through which the Bot was provided.
